<h2>Answers / First discoveries</h2>
<dl><dt>01</dt><dd>Three word groups. Reading begins with the rightmost group.</dd><dt>02</dt><dd>The tall shape on the right.</dd><dt>03</dt><dd>One dot below each copy.</dd><dt>04</dt><dd><span class="fa" lang="fa" dir="rtl">آ</span> has the mark above. Copy models: <span class="fa" lang="fa" dir="rtl">ا آ</span>.</dd><dt>05</dt><dd><span class="fa" lang="fa" dir="rtl">ب</span>; one dot below each copy.</dd><dt>06</dt><dd><span class="fa" lang="fa" dir="rtl">آب</span> means water.</dd><dt>07</dt><dd>A: <span class="fa" lang="fa" dir="rtl">آب</span>. B is only be.</dd><dt>08</dt><dd><span class="fa" lang="fa" dir="rtl">آ</span> comes first, at the right.</dd><dt>09</dt><dd>A: <span class="fa" lang="fa" dir="rtl">باد</span> means wind.</dd><dt>10</dt><dd>A = be; B = bo; C = ba.</dd><dt>11</dt><dd>ba <span class="fa" lang="fa" dir="rtl">بَ</span>; be <span class="fa" lang="fa" dir="rtl">بِ</span>; bo <span class="fa" lang="fa" dir="rtl">بُ</span>. Keep the letter dot below in all three.</dd></dl><p class="note">If direction was tricky, revisit page 7. For short vowels, return to pages 15–16.</p>

<h2>Answers / Shapes and joins</h2>
<dl><dt>12</dt><dd>Beginning be is <span class="fa" lang="fa" dir="rtl">بـ</span>. Separate be is <span class="fa" lang="fa" dir="rtl">ب</span>.</dd><dt>13</dt><dd>Alef prevents the following join.</dd><dt>14</dt><dd>Two words: water and wind.</dd><dt>15</dt><dd><span class="fa" lang="fa" dir="rtl">م</span>; <span class="fa" lang="fa" dir="rtl">ما</span> means we.</dd><dt>16</dt><dd>A = we; B = roof.</dd><dt>17</dt><dd><span class="fa" lang="fa" dir="rtl">دَر</span>; two letters. The vowel mark is not another letter.</dd><dt>18</dt><dd><span class="fa" lang="fa" dir="rtl">نـ</span> is beginning nun, with its dot above. <span class="fa" lang="fa" dir="rtl">بـ</span> is beginning be, dot below.</dd><dt>19</dt><dd><span class="fa" lang="fa" dir="rtl">نان</span> has two dots, one above each nun.</dd><dt>20</dt><dd>A = bread; B = door; C = water.</dd><dt>21</dt><dd><span class="fa" lang="fa" dir="rtl">باران</span> has five letters: be, alef, re, alef, nun.</dd></dl><p class="note">For gaps inside words, revisit page 18.
