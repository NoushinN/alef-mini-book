# Editorial guide

## Learning boundary

Eight letters, in teaching order: ا ب د م ر ن س ت. آ is taught with alef. Short-vowel signs َ ِ ُ are explicit reading aids, not additional letters. The unit is introductory Iranian Persian reading, not a full alphabet course or pronunciation replacement.

Letter-name labels are distinct from practice syllables: be is a letter name and also the Romanisation used for the practice syllable بِ; clarify orally if necessary.

## Exercises

There are 39 numbered activities. Answers 1–11: page 41; 12–21: page 42; 22–32: page 43; 33–39: page 44. Copying tasks use visible models rather than subjective scores. Final comprehension is three points, one per meaning. No automated pronunciation score is implied.

## Typography

Use Persian ک/ی when expanding vocabulary. Preserve short vowels on unfamiliar words, explicit language/direction spans, and generous space around dots. Do not use decoration near letter dots. Tables and English paragraphs are LTR; Persian examples are RTL. Keep one-page sections short enough for the A5 layout.

## Review before sale

- Have a fluent teacher check sounds, examples and joining explanations.
- Ask 3–5 true beginners to attempt the activities without help; note confusing instructions.
- Proof the actual RStudio/browser-generated PDF, particularly vowel positioning, page boundaries and all references.
- Verify any later audio/link destinations before inserting QR codes.
- Add factual author details only when supplied by the owner.
